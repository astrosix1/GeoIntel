GeoIntel API

Public, read-only REST API — real data, no API key required.
Base URL: https://<your-deployment>/api (locally, http://localhost:5000/api). Every endpoint below is unauthenticated and rate-limited to a default of 100 requests/minute (some endpoints, like bulk export, have a tighter limit noted inline). Responses are JSON unless noted otherwise. This documents the same endpoints the GeoIntel frontend itself uses — nothing here is a separate or reduced feed.

GET/crises

All active crises, with optional filtering.

Params: type, status, min_severity, days, include_analysis=true (adds real source-reliability + escalation data per crisis, at extra query cost).

{
  "count": 2,
  "crises": [
    {
      "id": "sample_kyiv",
      "type": "conflict",
      "title": "Kyiv Conflict Zone",
      "country": "Kyiv",
      "lat": 50.4501, "lon": 30.5234,
      "severity": 95, "confidence": 92,
      "domains": { "military": 0, "economic": 0, "political": 0,
                   "environment": 0, "technology": 0, "information": 0 },
      "is_verified": true,
      "date": "2026-09-24T01:56:27.546082",
      "status": "active"
    }
  ]
}

GET/crises/<id>

Full detail for one crisis, including its recent news and forecasts.

{
  "id": "sample_kyiv", "title": "Kyiv Conflict Zone", "country": "Kyiv",
  "severity": 95, "confidence": 92, "is_verified": true,
  "forecasts": [], "news": [], "domains": { "...": 0 }
}

GET/crises/<id>/reliability

Real source-reliability scoring: unique source count × a hand-curated per-outlet trust table. Never fabricated — "unknown" when no sources are indexed yet.

{ "reliability": "unknown", "score": 50, "source_count": 0, "sources": [] }

GET/crises/<id>/escalation

Real escalation trend derived from severity snapshots recorded on every sync. Returns "insufficient_data" honestly — never a fabricated trend — until at least 2 real readings exist for a crisis.

{
  "trend": "insufficient_data", "velocity": null, "severity_change": null,
  "current_severity": 95, "warning": null,
  "history": [ { "severity": 95, "date": "2026-09-24T01:56:58.267261" } ],
  "message": "Not enough historical readings yet to compute a trend for this crisis."
}

GET/crises/<id>/economic

economic_profile is a real trade-openness figure derived from actual WorldBank data for the crisis's country — null when no real economic data exists yet, never invented. sectors_typically_exposed is a category lookup by crisis type, not a measurement of this specific crisis.

{
  "impact_severity": "severe",
  "affected_countries": ["Kyiv"],
  "economic_data": {},
  "economic_profile": null,
  "sectors_typically_exposed": ["Energy", "Defense", "Shipping", "Aviation", "Finance"]
}

GET/actors

The curated state-actor roster (68 actors). economic is derived from real WorldBank GDP data; military/political/technology are null — no real data source for those exists in this app, so they're left unrated rather than guessed.

{
  "count": 68,
  "actors": [
    { "id": "US", "name": "United States", "region": "North America",
      "lat": 38.0, "lon": -97.0, "color": "#4488ff",
      "economic": 95, "military": null, "political": null, "technology": null,
      "is_nuclear": true }
  ]
}

GET/relationships

Curated real alliance/conflict/economic relationships between actors (81 total). Optional type param filters by relationship type.

{
  "count": 81,
  "relationships": [
    { "a": "US", "b": "CN", "type": "conflict",
      "label": "Strategic Rivalry / Tech War", "strength": 85, "stability": 40 }
  ]
}

GET/forecasts/<crisis_id>

Probabilistic forecast bands. method: "heuristic" marks a severity-derived estimate — not a statistical or historical model — so a future calibrated forecast can be told apart by the same field.

{
  "crisis_id": "sample_kyiv", "count": 4,
  "forecasts": [
    { "q": "Will armed hostilities intensify in the next 90 days?",
      "low": 10, "mid": 10, "high": 80, "method": "heuristic" }
  ]
}

      "url": "https://..." }

GET/economic/<country_code>

Real WorldBank economic indicators by ISO country code, most recent years first.

{
  "country": "US", "count": 10,
  "data": [
    { "country": "US", "year": 2025, "gdp": 30769.7, "gdp_growth": 2.16,
      "unemployment": 4.20, "exports": null, "imports": null,
      "inflation": null, "trade_balance": null }
  ]
}

GET/crises/export (10 req/min)

Bulk export of crisis data for your own analysis — CSV or JSON, with the same real reliability/verification/domain/stakeholder fields as the rest of this API, not a thin id/title/severity dump.

Params: format (csv default, or json), status, type (comma-separated list accepted), min_severity, country.

GET /crises/export?format=json&min_severity=80

{
  "count": 1,
  "crises": [
    { "id": "sample_kyiv", "title": "Kyiv Conflict Zone", "country": "Kyiv",
      "type": "conflict", "severity": 95, "confidence": 92,
      "status": "Active", "is_verified": true,
      "reliability": "unknown", "reliability_score": 50, "source_count": 0,
      "stakeholders": [],
      "domains": { "military": 0, "economic": 0, "political": 0,
                   "environment": 0, "technology": 0, "information": 0 } }
  ]
}
